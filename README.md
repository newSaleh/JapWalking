# المشي الياباني · Interval Walking

صفحة واحدة بسيطة (`index.html`) لمؤقّت المشي الياباني المتقطّع:
مشي سريع ثم هادئ بالتناوب، مع اختيار مدة كل فترة وعدد الجولات، وتسخين وتهدئة اختياريين.

- تنبيهات صوتية واهتزاز عند تغيّر المرحلة، وعدّ تنازلي في آخر 3 ثوانٍ.
- تبقي الشاشة مضاءة أثناء الجلسة (Wake Lock).
- تحفظ إعداداتك وأيام مشيك في المتصفح.

افتح `index.html` مباشرة، أو فعّل GitHub Pages على فرع `main`.
