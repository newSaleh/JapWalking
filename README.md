# المشي الياباني · Interval Walking

تطبيق ويب بسيط (`index.html`) لمؤقّت المشي الياباني المتقطّع: مشي سريع ثم هادئ بالتناوب.

- اختيار مدة السريع والهادئ وعدد الجولات، وتسخين وتهدئة بأي عدد دقائق أو بدون.
- قوالب محفوظة، والقالب المعلَّم بـ ★ يفتح تلقائيًا.
- شاشة جلسة سوداء بالكامل لتوفير البطارية، والوقت ضخم بلون المرحلة. المس الشاشة لإظهار الأزرار.
- تنبيه بالكلام أو بالنغمات أو صامت، وعدّ تنازلي في آخر 3 ثوانٍ.
- الجلسة تستمر لو أُغلقت الصفحة بالخطأ، ويمكن متابعتها أو إضافة جولة بعد الانتهاء.
- تعديل بيانات كل جلسة يدويًا (الجهد، المسافة، الخطوات، النبض، ملاحظات) وسجل للجلسات.
- زر «نسخ للتقييم» يجهّز نصًا جاهزًا للصقه في محادثة Claude.
- يعمل دون إنترنت بعد أول فتح، وله أيقونة عند إضافته للشاشة الرئيسية.

## التشغيل على الآيفون

1. فعّل GitHub Pages: Settings ← Pages ← Branch: `main` / root.
2. افتح الرابط في Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
